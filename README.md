# IPATool

[![GPLv3 License](https://img.shields.io/badge/license-GPLv3-orange.svg)](https://www.gnu.org/licenses/gpl-3.0.html)

IPATool 是一款 macOS 桌面应用，用于搜索 App Store 中的任意应用、获取许可并下载 IPA 文件到本地。支持多地区 Apple ID 管理、异步队列下载和操作日志追踪。
